Rows include epics whose approved start or approved due falls inside the selected month (TK planner), plus unresolved brought-forward epics whose approved due was before that month. Brought forward means the approved due date is before the selected month and the latest Jira epic status is still unresolved. Start slip means the approved start date is inside the selected month and no subtask worklog exists through month end. End slip means the approved due date is inside the selected month and the current Jira epic status is not resolved. Historical months use the latest canonical Jira status, so old-month completion status is approximate unless Jira snapshots are added later.

Week-by-week view across the previous, selected, and next month. Purple = epic plan bar. Blue = story bars (Diagnostics/Minimal). Green = hours logged. The red line marks actual completion. Teal line = today. Shaded column = selected month.
